# Design System

## Palette
- Background: #050B10
- Secondary: #0B141C
- Gold: #C89A4B
- Light Gold: #E0B866
- Muted Gold: #92703A
- Text: #E6D8BC
- Muted Text: #A99C84

## Typography
Reference style: high-contrast editorial serif for headings; clean sans-serif for navigation, metadata and body copy.
Suggested later: Playfair Display + Inter, subject to licensing/brand preference.

## Layout
- Max content width: ~1280px
- Desktop: 3-column About, 5-card Music, 2-part Tours
- Tablet: collapse to 2 columns
- Mobile: single-column sections; horizontal scroll for dense card sets

## Visual language
- Dark cinematic backgrounds
- Antique gold linework
- Thin borders
- Restrained glow
- Indian classical ornamental motifs
- Strong editorial hierarchy
